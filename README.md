PrepPilot 🎯

A smart interview preparation platform built using React.js to help users practice technical interview questions and track their preparation progress.

Features
Practice Mode for technical questions
Interview Mode with timed questions
Questions based on technology and category
Difficulty-based question filtering
Confidence tracking
Score calculation
Progress tracking
LocalStorage for saving user progress
Login and Signup
Protected routes
Responsive user interface
